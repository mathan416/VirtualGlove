Connect your console

Pair each console once. You can save multiple consoles on this UNO Q. VirtualGlove and R.O.B. Vision use each connection automatically when installed on both devices.

Pair console

  1. On the console you want to connect, run the command for its platform below. It prints a connection code that lasts five minutes.
    Run on your console
    PlatformCommandCopy command
    RetroPiesudo /var/lib/controller-router/pair-console
    Batocera/userdata/system/controller-router/pair-console
    Recalboxsh /recalbox/share/system/controller-router/pair-console

    These commands are included with the console installation of VirtualGlove or R.O.B. Vision. If the command is missing, install or upgrade the console software first.

  2. Enter that console’s hostname or IP address and paste its complete connection code below. Press Continue.
  3. The UNO Q Matrix now shows its confirmation sequence. After PN, read the first three digits and then the next three digits. Enter all six below and choose Connect. The sequence repeats for two minutes.

The Matrix code appears after Continue succeeds, not when you first open this page. To add another console, repeat these steps with that console.

Your consoles

Each console connects to one UNO Q at a time. You can turn off access for an individual app without removing the connection.

Trust this Setup page

The installer prints this UNO Q’s certificate fingerprint. Compare it with the certificate shown by your browser before accepting the local certificate. You can download the certificate to trust it on your own device. Do not continue if the fingerprints differ.

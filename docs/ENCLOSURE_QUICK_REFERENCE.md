# VirtualGlove Enclosure Assembly Quick Reference

This is the on-screen edition of the same single-page pictograph sheet supplied
as the printable PDF. Keep it open beside the printer or parts tray while you
assemble either enclosure.

![VirtualGlove pictograph assembly sheet for the UNO Q Case and Controller Dock](../hardware/enclosures/previews/virtualglove-enclosure-quick-reference.png)

The top row shows the **UNO Q Case**, with the Arduino hub outside the case. The
bottom row shows the **Controller Dock**, with the UNO Q and hub together in the
open service bay.

Use the [Controller Enclosure Guide](ENCLOSURE_GUIDE.md) for STL downloads,
printer settings, fit adjustments, detailed explanations, and troubleshooting.
